# Assets

Đặt file vào đúng thư mục sau:

## Nhân vật (bắt buộc để có sprite thật)

```
public/assets/characters/hoang_run_right_v2.png
```

Spritesheet: 1536×256, 6 frame ngang, mỗi frame 256×256.

Nếu chưa có file, game vẫn chạy với placeholder pixel.

## Ảnh ký ức (memory rain)

Thay các file placeholder trong `public/assets/memories/` bằng ảnh thật (jpg/png, 10–20 ảnh).
Cập nhật danh sách trong `src/data/memories.js`.

## Audio (tùy chọn)

```
public/assets/audio/birthday_bgm.mp3      — nhạc nền
public/assets/audio/birthday_letter.mp3   — audio thư sinh nhật
```
